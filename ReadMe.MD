# 2D篮球大乱斗 - 核心玩法Demo

灵感来源：任天堂大乱斗 + 4399 死神vs火影 + 篮球。这个demo先验证"移动+投篮+抢断+角色技能"
这个核心循环好不好玩，再往上叠加美术和更多功能。

## 如何运行

在你自己的电脑上(PyCharm / 你的conda环境)：

```bash
pip install pygame
python main.py
```

启动后先选模式：按 **1** 单人模式(对战AI)，按 **2** 双人模式(本地对战)。
选了单人模式后，再选AI难度：按 **1** EZ PZ(简单)，按 **2** Normal(普通)，
按 **3** Hard as Hell(超级难)。

## 操作

| 操作 | 玩家1(蓝) | 玩家2(红，双人模式下由真人操作) |
|---|---|---|
| 左右移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 投篮/捡球 | Space | Enter |
| 抢断 | S | ↓ |
| 冲刺技能(3秒冷却) | Left Shift | Right Ctrl |

单人模式下，玩家2由AI自动操作，不需要手动输入。

按 ESC 或关闭窗口退出。两名玩家都在场地右侧出生，一起进攻左边这一个
篮筐——类似真实3v3单筐半场对抗。谁先拿到 **12分** 谁获胜，屏幕上会弹出
"YOU WIN! You Are The GOAT!"；这时按 **Enter** 或 **R** 重开一局(回到模式
选择菜单)，按 **ESC** 退出整个程序。

## 当前实现了什么

- 双人本地对战，重力+跳跃+左右移动的基础物理
- **单人模式 + 简单规则AI对手**：开局菜单可以选1P(对战AI)或2P(本地对战)。
  选1P后还能进一步选AI难度——EZ PZ / Normal / Hard as Hell，三档分别对应
  不同的移动速度、冲刺频率、抢断范围和投篮命中率(具体数值见
  `constants.py`里的`AI_DIFFICULTY_PRESETS`，"Normal"就是原本调好的默认AI)。
  AI会追逐地上的球、走到投篮点后出手(大概率两分区、偶尔尝试三分)、
  追球权持有者尝试抢断、争顶篮板——具体逻辑见`entities.py`里的
  `Player.handle_ai`。每一档都保留了miss概率，避免"Hard as Hell"变成
  真正打不过的无敌AI
- 篮球有三种状态：被持有(held) / 自由弹跳(loose) / 飞行中(flying)
- 靠近对方持球者按抢断键可以抢球(有冷却，防止无脑连按)
- 持球时按投篮键，球会沿抛物线飞向篮筐，进筐算得分
- 每个角色目前有一个共同的"冲刺"技能(短时间内速度暴增)，
  头顶有个绿色冷却进度条
- **角色动画系统**：角色会根据当前状态(站立/跑动/跳跃)自动切换动作。
  没放贴图时用程序化的简笔小人代替，保证角色"能动"不依赖美术资源；
  放好贴图后自动切换成真正的雪碧图动画，具体见`assets/SPRITE_GUIDE.md`
- **真实球场布局**：篮筐挂在场地左侧墙上，地面画了压扁风格的
  三分线、两分线(中距离标线)、罚球区(禁区)、罚球圈、半场线，
  参考经典街球游戏(如NBA Jam)的画法
- **自定义计分规则**：出手点在三分线外算2分，压线或三分线内算1分
  (用投篮瞬间投篮者离篮筐的直线距离判定)
- **胜负判定**：谁先拿到`WINNING_SCORE`(默认12)分谁获胜，游戏立刻暂停
  并叠加半透明遮罩显示获胜者名字、"YOU WIN!"、"You Are The GOAT!"；
  按Enter/R重开一局(回到模式选择菜单)，按ESC退出整个程序

## 文件结构

```
basketball_demo/
├── constants.py    # 所有可调参数(速度、重力、篮筐/球场标线位置、AI行为参数等)
├── animation.py     # 动画系统：贴图雪碧图加载 + 无贴图时的程序化占位动画
├── entities.py      # Player 和 Ball 类，游戏逻辑核心(含AI逻辑)
├── main.py          # 主循环，模式选择菜单，输入映射，画面绘制
├── assets/
│   ├── SPRITE_GUIDE.md
│   ├── ball.png     # (需要你自己放)篮球贴图，3帧：手里/空中/地面
│   ├── player1/     # 把 idle.png / run.png / jump.png 放这里
│   └── player2/     # 同上
└── README.md
```

## 接下来的任务

1. **放入真正的贴图**：按`assets/SPRITE_GUIDE.md`里的规范，
   把找好的2D人物/动漫/动物贴图放进`assets/player1/`和
   `assets/player2/`，篮球贴图放进`assets/ball.png`。代码会自动识别
   并播放，不用改任何代码。

2. **验证手感**：自己玩几局，感受移动速度、跳跃高度、
   投篮判定范围、球场标线的比例是不是舒服。这些参数全部在
   `constants.py`里，改起来很快，不用动逻辑代码。

3. **加差异化技能**：现在两个角色技能一样(都是冲刺)。
   可以在`Player.__init__`里加一个`skill_type`参数，
   在`handle_input`里用if-else分支处理不同技能逻辑，比如：
   - 巨人角色：投篮/扣篮时有范围震退效果
   - 敏捷角色：二段跳
   - 魔法角色：球飞行轨迹带弧线漂移

4. **音效和粒子效果**：投中/抢断/冲刺时加点简单反馈
   (颜色闪烁、简单音效)，手感会提升很多。

5. **进球得分的画面反馈**：现在进球只是分数默默+1/+2。
   在篮筐附近加一个短暂浮现的"+1"/"+2"文字提示，
   能让1分和2分的区别更直观。

6. **继续调优AI难度**：三档难度的具体数值都在`constants.py`的
   `AI_DIFFICULTY_PRESETS`里(移动速度倍率、冲刺频率、抢断范围、
   投篮miss率、选三分概率)，改起来很快，不用碰`Player.handle_ai`
   的逻辑代码。以后可以考虑：
   - 给AI加一个短暂的"反应延迟"，让它显得不那么"秒反应"，
     难度越低延迟越长
   - 让"Hard as Hell"档AI在被断球后有概率立刻用冲刺技能反抢，
     增加压迫感
