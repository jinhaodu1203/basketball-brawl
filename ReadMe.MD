# Version 0.4 — Character Ability Framework

## 新角色

- **DJH**：专属技能 `Lightning Dash`
- **Gorilla**：专属技能 `Ground Slam`
- **Ninja**：专属技能 `Shadow Jump`（空中二段跳）

## 操作

| 操作 | 玩家1 | 玩家2 |
|---|---|---|
| 移动 | A / D | ← / → |
| 跳跃 | W | ↑ |
| 投篮/捡球 | Space | Enter |
| 抢断 | S | ↓ |
| 角色技能 | Left Shift | Right Ctrl |
